Uma variável é, conceitualmente, um espaço nomeado para armazenar um valor.

int       → tipo do dado
idade     → nome da variável
=         → atribuição
23        → valor

int idade = 23;

significa:

Crie uma variável chamada idade, capaz de armazenar um int, e coloque 23 nela.

Podemos posteriormente alterar o valor:

int idade = 23;

idade = 24;
