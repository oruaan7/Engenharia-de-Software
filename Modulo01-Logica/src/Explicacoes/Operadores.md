Podemos realizar operacoes matematicas:

int a = 10;
int b = 3;

System.out.println(a + b); // 13
System.out.println(a - b); // 7
System.out.println(a * b); // 30
System.out.println(a / b); // 3
System.out.println(a % b); // O % é chamado de módulo/resto da divisão.

Também podemos comparar valores.

==    igual
!=    diferente
>     maior
<     menor
>=    maior ou igual
<=    menor ou igual

Podemos combinar condições.

AND — &&

As duas condições precisam ser verdadeiras:

idade >= 18 && idade <= 60

OR — ||

Pelo menos uma precisa ser verdadeira:

idade < 18 || idade > 60

NOT — !

Inverte o resultado:

!true
