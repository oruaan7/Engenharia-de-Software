O computador precisa saber que tipo de informação está sendo armazenada.

Os principais tipos primitivos que vamos utilizar inicialmente são:
Tipo	  Exemplo	   Utilização
int	23	  números      inteiros
long	  100000L	   inteiros maiores
double	  7.5	       números decimais
float	  7.5f	       decimais
boolean	  true	       verdadeiro/falso
char	  'A'	       um caractere
String    nome         texto
